# Viva Brand Experience

Crie um website premium, moderno e extremamente visual para a marca:

VIVA ACTIVE NATURAL CARE

IMPORTANTE:

Estou anexando imagens digitais oficiais dos produtos da marca.

A PRIMEIRA IMAGEM, que apresenta todos os produtos juntos, deve ser utilizada como a PRINCIPAL IMAGEM DO SITE.

Não redesenhe os produtos.

Não altere suas embalagens.

Não altere logotipo, textos ou proporções presentes nas imagens.

Use as imagens fornecidas como referência visual oficial da marca.

==================================================

1. CONCEITO DO SITE

==================================================

Quero uma experiência de uma única página, com rolagem vertical contínua.

Não criar várias páginas.

O usuário deve simplesmente entrar no site e começar a rolar para baixo, descobrindo a marca progressivamente.

A experiência deve ser semelhante a uma apresentação digital premium de uma marca de cosméticos.

Quero:

- moderno;

- sofisticado;

- natural;

- premium;

- clean;

- elegante;

- feminino e/ou unissex dependendo das imagens fornecidas;

- contemporâneo;

- visualmente marcante;

- muito bem organizado.

Não quero um site genérico de cosméticos.

Quero que pareça uma marca real e estabelecida.

==================================================

2. PRIMEIRA TELA — IMAGEM PRINCIPAL

==================================================

A primeira imagem enviada, mostrando TODOS OS PRODUTOS, deve ocupar a primeira tela inteira do site.

Ela deve funcionar como o HERO / BACKGROUND inicial.

Quando o usuário abrir o site:

A imagem deve aparecer imediatamente em tela cheia.

Não colocar uma grande quantidade de texto sobre ela.

Utilizar apenas:

VIVA

ACTIVE NATURAL CARE

e, se a composição permitir:

NATURAL CARE. ACTIVE LIFE.

ou deixar a área textual vazia caso isso prejudique a imagem.

A prioridade absoluta da primeira tela é a fotografia dos produtos.

Criar uma experiência cinematográfica.

Adicionar apenas:

- leve overlay;

- iluminação sutil;

- animação muito discreta;

- indicação de "scroll" na parte inferior.

Não esconder os produtos.

==================================================

3. TRANSIÇÃO DO HERO

==================================================

Quero uma transição muito bonita quando o usuário começar a rolar.

A imagem inicial deve:

- diminuir suavemente;

- sofrer um pequeno efeito de zoom-out;

- desaparecer gradualmente;

- revelar a primeira seção do site.

Pode utilizar:

- parallax;

- fade;

- scale;

- blur extremamente discreto;

- mudança gradual de fundo.

A sensação deve ser de que a fotografia está dando lugar à experiência da marca.

Não utilizar transições exageradas.

==================================================

4. IDENTIDADE VISUAL

==================================================

A identidade visual deve ser baseada principalmente nas próprias imagens dos produtos fornecidos.

Analise visualmente as embalagens e extraia delas:

- cores;

- tipografia;

- linguagem visual;

- elementos gráficos;

- sensação de marca.

NÃO invente uma identidade completamente diferente da embalagem.

O site deve parecer uma extensão natural dos produtos.

Caso a paleta das imagens seja clara, trabalhar com:

- branco;

- tons naturais;

- bege;

- creme;

- verde suave;

- tons terrosos;

- cinza muito claro;

APENAS SE essas cores forem coerentes com os produtos fornecidos.

Caso as embalagens tenham outra paleta dominante, adaptar o site a ela.

A identidade dos produtos é a fonte principal.

==================================================

5. NAVEGAÇÃO

==================================================

O site inteiro deve ser UMA ÚNICA PÁGINA.

Não criar:

- loja separada;

- página de produtos;

- página sobre;

- página contato;

- login;

- checkout.

Tudo deve acontecer na mesma experiência de rolagem.

Pode existir uma navegação interna extremamente discreta por âncoras, se realmente melhorar a experiência.

Não quero um menu pesado.

==================================================

6. SEÇÃO — A VIVA

==================================================

Depois do HERO, apresentar a marca.

Título:

VIVA

ACTIVE NATURAL CARE

Texto:

[INFORMAÇÃO A DEFINIR]

IMPORTANTE:

Como ainda não forneci as informações oficiais da empresa, NÃO invente missão, história, fundadores, origem, ingredientes ou posicionamento específico.

Utilize placeholders elegantes como:

"Descrição da marca em breve."

ou:

"Conteúdo a definir."

A estrutura deve estar pronta para substituir posteriormente.

==================================================

7. PRODUTOS

==================================================

Criar uma seção visual apresentando os produtos individualmente.

Utilizar as imagens digitais fornecidas.

NÃO criar produtos fictícios.

NÃO inventar nomes.

NÃO inventar ingredientes.

NÃO inventar benefícios.

Para qualquer informação que ainda não foi fornecida, utilizar:

[INFORMAÇÃO A DEFINIR]

A apresentação dos produtos deve ser extremamente visual.

Cada produto pode ocupar uma grande área da tela.

Exemplo:

PRODUTO

[IMAGEM GRANDE]

[Nome do produto]

[Descrição a definir]

[Ingredientes a definir]

[Benefícios a definir]

==================================================

8. EXPERIÊNCIA DOS PRODUTOS

==================================================

Não quero simplesmente três ou quatro cards.

Criar uma experiência editorial.

Ao rolar:

Produto 01 aparece.

A imagem entra suavemente.

O nome aparece.

Depois, conforme o usuário continua:

Produto 02.

Depois:

Produto 03.

E assim sucessivamente de acordo com a quantidade real de produtos fornecidos.

Utilizar transições suaves entre eles.

==================================================

9. INGREDIENTES NATURAIS

==================================================

Criar uma seção:

NATUREZA EM CADA DETALHE.

Por enquanto:

[INFORMAÇÕES SOBRE INGREDIENTES A DEFINIR]

Não inventar ingredientes.

Criar apenas a estrutura visual.

Quando as informações forem adicionadas futuramente, será possível substituir facilmente os placeholders.

==================================================

10. BENEFÍCIOS

==================================================

Criar uma seção:

CUIDADO QUE FAZ PARTE DA ROTINA.

Conteúdo:

[BENEFÍCIOS DOS PRODUTOS A DEFINIR]

Não criar alegações cosméticas ou dermatológicas que não foram fornecidas.

Deixar a estrutura pronta.

==================================================

11. FILOSOFIA DA MARCA

==================================================

Criar uma seção editorial:

VIVA.

[PROPÓSITO DA MARCA A DEFINIR]

[VALORES DA MARCA A DEFINIR]

A seção deve parecer premium e não burocrática.

Não utilizar uma tabela tradicional.

==================================================

12. CIÊNCIA E QUALIDADE

==================================================

Criar uma seção:

CIÊNCIA + NATUREZA.

Estrutura preparada para futuramente receber:

- composição;

- ativos;

- processos;

- testes;

- qualidade;

- sustentabilidade;

- informações técnicas.

Por enquanto:

[INFORMAÇÕES A DEFINIR]

Não inventar certificações.

Não inventar testes.

Não afirmar que os produtos são veganos, cruelty-free, orgânicos, dermatologicamente testados ou certificados sem que isso seja fornecido.

==================================================

13. SUSTENTABILIDADE

==================================================

Criar uma seção:

BELEZA COM PROPÓSITO.

Conteúdo:

[INFORMAÇÕES DE SUSTENTABILIDADE A DEFINIR]

Deixar a estrutura visual pronta.

Não inventar materiais das embalagens ou políticas ambientais.

==================================================

14. EXPERIÊNCIA PREMIUM

==================================================

Quero que o site tenha bastante espaço negativo.

Não colocar tudo em cards.

Utilizar:

- imagens grandes;

- tipografia elegante;

- títulos grandes;

- pequenos textos;

- divisores;

- números;

- microtipografia;

- transições;

- animações discretas.

O site deve respirar.

==================================================

15. INTERATIVIDADE

==================================================

Quero uma experiência mais interativa e dinâmica.

Utilizar:

- scroll animations;

- parallax suave;

- imagens entrando progressivamente;

- textos aparecendo conforme o scroll;

- pequenas transições;

- hover elegante;

- mudança de escala;

- mudança sutil de fundos;

- indicador de progresso da página.

Adicionar uma pequena barra de progresso discreta.

Não exagerar nos efeitos.

A experiência deve parecer premium, não um site de videogame.

==================================================

16. PRODUTOS EM DESTAQUE

==================================================

Criar pelo menos uma seção onde os produtos possam ocupar quase toda a tela.

Uma possibilidade:

imagem grande do produto à esquerda;

informações à direita.

No mobile:

imagem primeiro;

informações abaixo.

A imagem deve permanecer protagonista.

==================================================

17. MOBILE

==================================================

Criar uma versão MOBILE realmente planejada.

Não apenas reduzir o desktop.

No celular:

- imagem principal em tela cheia;

- produtos grandes;

- textos legíveis;

- espaçamento confortável;

- animações suaves;

- zero overflow horizontal;

- nenhuma imagem distorcida;

- nenhum texto cortado.

A primeira imagem deve continuar sendo a grande protagonista da experiência mobile.

==================================================

18. FOOTER

==================================================

Finalizar de maneira extremamente limpa.

VIVA

ACTIVE NATURAL CARE

[Informações de contato a definir]

[Instagram a definir]

[Site/contato a definir]

Não inventar informações.

==================================================

O resultado precisa parecer uma marca de cosméticos naturais real.

Não quero aparência de trabalho escolar.

Não quero excesso de elementos.

Não quero um dashboard.

Não quero uma loja virtual.

Quero uma experiência de marca.

O visitante deve sentir:

NATURAL

PREMIUM

QUALIDADE

SOFISTICAÇÃO

22. PERFORMANCE

==================================================

O site deve ser rápido.

Utilizar:

- lazy loading;

- imagens otimizadas;

- animações leves;

- código limpo;

- componentes reutilizáveis;

- responsividade completa.

Não sacrificar performance pelos efeitos.

==================================================

23. ACESSIBILIDADE

==================================================

Garantir:

- bom contraste;

- textos legíveis;

- alt text nas imagens;

- navegação funcional;

- estrutura semântica;

- experiência adequada para mobile.

24. REVISÃO FINAL

==================================================

Antes de finalizar:

Verifique:

- nenhuma imagem cortada;

- nenhuma imagem distorcida;

- nenhum produto alterado;

- nenhum texto ilegível;

- nenhum overflow horizontal;

- nenhuma animação quebrada;

- nenhum erro de console;

- responsividade desktop;

- responsividade mobile;

- espaçamentos;

- tipografia;

- consistência visual;

- carregamento das imagens.

A primeira imagem enviada deve obrigatoriamente ser a primeira impressão do site.

O resultado final deve parecer uma experiência digital de lançamento de uma marca premium de cosméticos naturais.
